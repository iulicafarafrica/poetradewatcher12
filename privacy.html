Privacy policy

Poe Trade Watcher 2.9.55 · last updated 21 November 2026

Poe Trade Watcher is an unofficial fan-made browser extension for Chrome, Edge and Firefox. It has no accounts, no analytics, no ads and does not sell or share data with anyone.

What is stored on your device

Saved trade items, gear imported from a build, builds, watched listings, search history, price history snapshots and settings are stored locally in your browser profile (the extension's local storage: chrome.storage.local in Chrome and Edge, browser.storage.local in Firefox). Price history keeps the last 50 price checks of each item you save or watch. None of it leaves your device unless you export a backup or enable sync for your settings.

The same local storage holds small caches that avoid repeated work, for example: item pictures taken from the trade pages you saved (capped at a few hundred), the public Craft of Exile data files (kept for 12 hours) and recently fetched currency rates. Removing the extension deletes all of it.

Build import

Build codes from Path of Building (for PoE 1 and PoE 2), pobb.in or Mobalytics ("Share your Build") are decoded inside the extension, on your own device. Pasting a code contacts no server and opens no build page. The code itself is not kept: only the equipped gear you choose to import is saved, as ordinary items inside a build. Flasks and gems are skipped, and no item pictures are fetched for imported gear.

Importing gear uploads nothing about your items. The import also refreshes the public Craft of Exile data files (see Network requests) so affix names can be filled in: the extension reads those files once when they are not cached and remembers the result. Without them the gear still imports, only the affix names cannot be matched to the Craft of Exile tables.

Optional sync

If you enable sync for your settings, they are stored in your browser account through the browser's own sync (Chrome Sync in Chrome and Edge, Firefox Sync in Firefox; legacy bookmark data from older versions, if any, is included). Saved items and watchers are never synced. Your browser vendor's privacy policy applies to that storage.

Network requests

  • www.pathofexile.com – reads public trade listings of the page you are viewing (item data, seller character name, whisper text, price, stash position). The same public trade API is used to fetch the details of a single listing when you save it, watch it, copy its whisper or refresh its price, so the stored data matches the page. Watcher refreshes reuse your existing Path of Exile session so the public API can answer them; the extension never sends your session data anywhere else. A single search is created through the same API when you ask for an item's trade link. If you watch a search, the extension re-runs that exact search on the same public API on its own schedule and reads the listings it returns, so a watched search keeps working while the trade tab is closed; nothing about you is sent, and results are never kept beyond the listing ids it has already seen.
  • web.poecdn.com – Path of Exile's image server. Item pictures are loaded from there by the browser itself when a saved or watched item shows its icon; no other data is sent with that request.
  • cdn.poe2db.tw and cdn.poedb.tw – show the ascendancy class icon next to a build and in the build picker. Only that image file is requested.
  • poe.ninja – fetches public currency exchange rates used to convert prices.
  • mobalytics.gg – only if you click "Read page": the extension looks for the build tab you already have open, then reads the pictures and trade links of that page and copies them onto your saved items. The optional host permission is requested at that click, never at install, and reading the page sends no request anywhere. Without that permission the extension cannot see any other tab's address.
  • beta.craftofexile.com – only if you open a Craft of Exile link (the "Open in Craft of Exile" action, including on an item imported from a build). It downloads the public data files the Craft of Exile site itself loads (base item ids and modifier tables) so the item can be opened with its modifiers. The host permission is optional and requested the first time you use that action, never at install. The files are cached in your browser profile for 12 hours. These downloads carry nothing about your items; item text travels inside the tab address instead (see Craft of Exile links).
  • Discord webhook and ntfy – only if you configure them. Alerts you enable (item sold, price change, target reached, whitelisted seller) are sent to the endpoint you provide and contain the item name, price and seller character name. Discord needs an optional host permission (discord.com and the legacy discordapp.com), requested the first time you save or test a webhook, never at install. For ntfy.sh the same optional permission is requested on demand; a self-hosted ntfy URL is contacted directly at the address you enter (HTTPS, or plain HTTP only for localhost).

Craft of Exile links

The "Open in Craft of Exile" action opens a Craft of Exile page in a new tab. The item text is carried inside that page's address (eimport=), so Craft of Exile receives the item when the tab loads; that is how the import works. The extension does not upload the item anywhere else and never sends your items to Craft of Exile from the background. Items imported from a build use exactly the same link. For unique items, and to fill in affix names on imported items, the extension also reads the site's public data files (see Network requests above); nothing else is downloaded or sent.

Secrets never leave your profile

The Discord webhook URL, the ntfy topic and whisper tokens are kept in local storage only. They are removed from exported backup files and are not included in sync payloads, so they are never uploaded to your browser account or to a backup file you share.

What is never collected

No email, no passwords, no browsing history outside the Path of Exile trade searches you make yourself, no location, no tracking and no telemetry. The extension reads only the official Path of Exile trade pages it is installed on, plus a build page you explicitly ask it to read with the optional permission above. Build codes you paste are decoded on your device and are never uploaded.

User Data policy (Limited Use)

Data handling in this extension complies with the Chrome Web Store User Data Policy, including the Limited Use requirements, and with Mozilla's Add-on Policies for the Firefox version. Data is used only to provide the features described on this page, is not sold, is not transferred to advertising platforms, data brokers or other resellers, and is not used to determine creditworthiness.

Your control

  • Remove alerts by clearing the Discord webhook or ntfy topic in Settings.
  • Delete saved or imported items with the delete button, delete a build to drop the gear it brought in, and erase everything by removing the extension.
  • Export a full backup any time from Settings.
